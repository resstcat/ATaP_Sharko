📄 Опис коду
Цей веб-додаток реалізований за допомогою бібліотеки Streamlit та SQLite (легка вбудована СУБД). Він призначений для:

Демонстрації небезпечної поведінки при роботі з SQL (через введення зловмисного коду).

Пояснення, як захистити свій застосунок за допомогою параметризованих запитів.

Показу, як обробляти помилки при роботі з базою даних у Python.



⚙️ Основні функції додатку
1. Ініціалізація бази даних
Функція init_db() створює таблицю users, якщо вона ще не існує. Це потрібно при першому запуску.

2. Безпечне додавання користувача
Функція add_user(username) вставляє нове ім’я користувача до бази, використовуючи параметризований запит:
cursor.execute("INSERT INTO users (username) VALUES (?)", (username,))

Це захищає від SQL-ін’єкцій.

3. Виведення всіх користувачів
Функція show_users() виводить усіх користувачів з таблиці users.

4. Обробка помилок
Усі операції з базою даних обгорнуті в try-except, що дозволяє:

- виявляти помилки;

- виводити зручні повідомлення замість аварійного завершення програми.

5. Streamlit-інтерфейс:
- Заголовок і пояснення теми.

- Поле для введення імені користувача.

- Кнопка для додавання користувача.

- Список усіх користувачів.


Що демонструє цей додаток
🔐 Захист від SQL-ін’єкцій:

Користувач вводить довільний текст у поле імені, наприклад:
'); DROP TABLE users; --

Але це не викликає небажаних дій, оскільки використовується параметризований запит, який розпізнає це як текст, а не як SQL-код.



Як користуватися додатком
1. Встановлення залежностей
У терміналі виконай:
pip install streamlit

3. Збереження коду
Скопіюй код у файл, наприклад:
sql_injection_protection.py

3. Запуск Streamlit-додатку
У терміналі:
streamlit run sql_injection_protection.py

5. Використання через веб-браузер
Після запуску відкриється браузер або буде показано посилання, наприклад:
http://localhost:8501

5. Тестування функціоналу
Введи коректне ім’я користувача та натисни "Додати користувача".

Введи шкідливий SQL-код, наприклад:
'); DROP TABLE users; --

і переконайся, що додаток працює безпечно — таблиця не знищується.
